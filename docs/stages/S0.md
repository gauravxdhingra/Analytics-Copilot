### W5. Scaffold, with the first typed slice
- **What:** create the layout from ARCH §14 (`apps/ services/ mcp-servers/ packages/ data/ deploy/ docs/`) with minimal READMEs; a `uv` workspace; root `Makefile` (`lint`, `typecheck`, `test`, stubs for `up`, `down`, `eval`); and one real slice, `packages/schemas`, holding `Money`, `Provenance`, `Evidence`, `Claim`, `AgentResult` from Analytics Copilot.md §3.

### W6. CI
- **What:** GitHub Actions on pull requests and `main`: lint, type check, tests, secret scan (gitleaks), dependency audit (`pip-audit`/`uv`), static analysis (e.g. Semgrep or Bandit), filesystem and IaC scan (Trivy), markdown link and ADR-index check, `LICENSE` check. Actions pinned by SHA, `permissions:` read-only by default, no long-lived cloud keys. Dependabot for actions and dependencies. Branch protection requiring the checks is applied by the owner in GitHub settings.
- **Spec:** ARCH §5.3 supply chain, §7.4 delivery.
- **Owner:** Claude writes; `infra-reviewer` reviews.
- **Proof:** a deliberately failing PR (planted fake secret, type error, broken link) turns CI red, then it is reverted and CI is green.
- **Depends on:** W5.

### W7. Local pre-commit

- **Owner:** Claude.
- **Proof:** committing a planted secret locally is rejected.

## Definition of done (per item)

- Checks or tests for the item pass (locally and in CI once W6 exists).
- `/pre-pr` clean for the PR containing it.
- Docs and ADRs updated; `spec-guardian` clean.
- No new tool without a trace span and policy entry (not expected in S0).
- Threat model updated if the attack surface changed (W6's CI permissions and W5's dependencies count).
- No secrets, real data or employer-specific names.
